# AI For Business Claude Skills

Free Claude skills from Brian Hanson / AI For Business. Built for business owners, not developers. Each one is a ZIP you upload to your Claude account in about 60 seconds.

## The skills

| Skill | What it does | Download |
|---|---|---|
| **Appreneur Blueprint** | Takes an app idea from "should I build this" to a sellable product. Validates, writes the PRD, plans the build batches, hardens, packages, lists. | [appreneur-blueprint.zip](appreneur-blueprint.zip) |
| **First Customer Finder** | Give it a URL or an idea. Get a source-linked list of people showing public signs they'd buy, with scores, openers, and a 7-day plan. | [first-customer-finder.zip](first-customer-finder.zip) |
| **Agency Delivery** | The client delivery system for websites and apps: discovery, proposal, 3-batch build, QA, launch, handoff, care plan. | [agency-delivery.zip](agency-delivery.zip) |
| **Lovable Production** | Makes a Lovable + Supabase app safe for real customers. Security audit, priority ladder, batch prompts you paste into Lovable. | [lovable-production.zip](lovable-production.zip) |

Want Claude to write in your voice? That one lives in its own repo: [voice-skill-builder](https://github.com/realbrianhanson/voice-skill-builder).

## Install (claude.ai or Claude Desktop)

1. Turn on the switch once: click your initials (bottom left) → **Settings** → **Capabilities** → turn on **Code execution and file creation**.
2. Download a ZIP above. Don't unzip it.
3. In the left sidebar: **Customize** → **Skills** → **+** → **Create skill** → **Upload a skill**. Pick the ZIP.
4. Make sure the toggle next to it is on.
5. Start a new chat and ask for the job in plain English.

On a Team or Enterprise plan, an admin also has to turn on Skills under **Organization settings → Skills**.

## Try this first

- Appreneur Blueprint: "I have an app idea: [2 sentences]. Should I build it?"
- First Customer Finder: "Find my first 10 customers for [your website]."
- Agency Delivery: "A dentist wants a new website. Write the proposal and scope."
- Lovable Production: "Audit my Lovable app for anything that would break with real users."

## If a skill doesn't fire

Say its name in your prompt: "Use the agency-delivery skill to..." If it still doesn't load, check the toggle is on and that you started a new chat after installing.
